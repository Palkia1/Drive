# Verkeersbord-bestanden

Zet hier de geleverde bordbestanden neer, met bestandsnaam = exact de officiële code
(zie ../../verkeersborden-index.md voor de volledige lijst), bijvoorbeeld:

    A1.svg
    A1zone.svg
    B6.svg
    C7a.svg

Formaat: SVG (voorkeur) of PNG met transparante achtergrond, vierkant canvas.

Borden met een cijfer erop (A1, A2, A4, A5, A1zone, A2zone, C17, C18, C19, C21):
lever het bord ZONDER cijfer — de app zet het getal er zelf overheen.
